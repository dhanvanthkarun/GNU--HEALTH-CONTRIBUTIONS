GNU Health DICOM Binary Plugin
###############################

This plugin has been developed as part of GNU Health[1] 

Functionality :
The main functionality is to allow upload DICOM format image data.


What is DICOM format file?
DICOM (Digital Imaging and Communications in Medicine) is a standard protocol for managing and transmitting medical images and related data that is used in many healthcare facilities. DICOM is the international standard for communication and management of medical images and data.

This tool has been utilized in the 'Radiology' module of GNU Health for uploading image data to a configured Orthanc server.
